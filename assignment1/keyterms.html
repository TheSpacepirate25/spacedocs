Key Internet Terms

Here are some important terms that appear in the history of the internet.

  • Packet switching: A method that breaks data into small packets which are sent separately across the network and reassembled at the destination.
  • TCP/IP: The core set of communication rules that let different computers and networks talk to each other on the internet.
  • DNS (Domain Name System): The “phone book” of the internet that turns names like example.com into IP addresses that computers use.
  • World Wide Web (WWW): A system of linked documents (web pages) that run on top of the internet, invented by Tim Berners-Lee.
