💻 UNIX Commands 💻



Command Usage Description Difficulty
ls ls -l Lists all the files in the directory you are currently in. The -l argument provides additional information. Easy
nano nano (filename) Opens the specified file in the built-in Nano text editor. Easy
cd cd (directoryname) Changes your location to the specified folder. Typing in cd ../ will move your location back a folder. Medium
find find (arguments) Looks for a file. This command is quite hard to use since you need to specify a lot of arguments to find what you are looking for. Hard

Other cool commands include:

  • mkdir
  • pwd
  • touch
  • rm
  • rmdir
  • cp
  • mv
