How the Web Works

When you visit a website, your computer and a web server talk to each other over the internet to show you a page.

A web browser is a program like Chrome or Edge that lets you view web pages. A web server is a computer that stores websites and sends them to browsers.

A URL (like https://example.com) is the address of a web page. Your browser uses it to find the right server.

Basic steps when you visit a site:

  • You type a URL into the browser.
  • The browser asks DNS to find the server’s IP address.
  • The browser sends an HTTP request to the server.
  • The server sends back HTML and other files.
  • The browser displays the page on your screen.
